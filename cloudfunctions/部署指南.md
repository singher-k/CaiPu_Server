## 2. 部署步骤

### 步骤1：打开微信开发者工具
1. 下载并安装微信开发者工具
2. 导入本项目（选择 project.config.json 所在目录）

### 步骤2：关联云开发环境
1. 点击微信开发者工具右侧的「云开发」
2. 点击「创建环境」
3. 选择「按量付费」或「包年包月」
4. 等待环境创建完成（约1-2分钟）

### 步骤3：配置环境ID
1. 复制环境ID（如：caipu-xxxxx）
2. 修改 `project.config.json` 中的环境配置
3. 或在小程序代码中配置环境ID

### 步骤4：上传云函数
1. 右键点击 `cloudfunctions/` 目录
2. 选择「上传并部署：云端安装依赖」
3. 等待部署完成

## 3. 数据库集合

需要手动创建以下集合：

### users 集合
```
集合名：users
权限：所有用户可读，仅创建者可读写
字段：
- _id (自动生成)
- openid (用户openid)
- nickName (昵称)
- avatarUrl (头像)
- createdAt (创建时间)
- updatedAt (更新时间)
```

### 其他集合（根据需求创建）
```
- recipes (菜谱)
- friends (好友)
- reservations (预约)
- messages (消息)
```

## 4. 前端调用示例

```javascript
// 调用登录云函数
wx.cloud.callFunction({
  name: 'login',
  data: {
    code: res.code,
    nickName: userInfo.nickName,
    avatarUrl: userInfo.avatarUrl
  },
  success: res => {
    console.log('登录成功:', res.result)
  },
  fail: err => {
    console.error('登录失败:', err)
  }
})

// 调用用户更新云函数
wx.cloud.callFunction({
  name: 'userUpdate',
  data: {
    userId: this.data.userId,
    nickName: nickName,
    avatarUrl: avatarUrl
  },
  success: res => {
    console.log('更新成功:', res.result)
  }
})
```

## 5. 注意事项

1. **环境ID**：确保前端和云函数使用相同的环境ID
2. **权限配置**：在微信公众平台配置数据库权限
3. **免费额度**：云开发有免费额度，个人小程序足够使用
4. **域名配置**：云开发自动支持HTTPS，无需配置域名
