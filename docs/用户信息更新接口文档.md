# 用户信息更新接口文档

## 接口概述

新增了一个用户信息更新接口，允许前端获取用户真实头像和昵称后更新到服务器数据库。

## 接口地址

```
POST /api/user/update
```

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | string | 是 | 用户ID（从登录响应中获得） |
| nickName | string | 否 | 用户昵称 |
| avatarUrl | string | 否 | 用户头像URL |

## 请求示例

```json
{
  "userId": "temp-1766741832854",
  "nickName": "张三",
  "avatarUrl": "https://wx.qlogo.cn/mmopen/vi_32/Q0j4TwGTfTLL1sT6..."
}
```

## 响应示例

### 成功响应 (200)

```json
{
  "success": true,
  "message": "用户信息更新成功",
  "user": {
    "id": "temp-1766741832854",
    "openid": "oAUN014of1nsMf70IpqCVgNHyGyQ",
    "nickName": "张三",
    "avatarUrl": "https://wx.qlogo.cn/mmopen/vi_32/Q0j4TwGTfTLL1sT6...",
    "createdAt": "2025-12-26T09:37:12.854Z"
  }
}
```

### 错误响应

#### 400 - 参数错误
```json
{
  "success": false,
  "message": "用户ID不能为空"
}
```

#### 404 - 用户不存在
```json
{
  "success": false,
  "message": "用户不存在"
}
```

#### 500 - 服务器错误
```json
{
  "success": false,
  "message": "更新用户信息失败",
  "error": "详细错误信息"
}
```

## 前端使用示例

```javascript
// 获取用户信息并更新到服务器
wx.getUserProfile({
  desc: '用于完善用户资料',
  success: (res) => {
    const userInfo = res.userInfo;
    
    // 更新用户信息到服务器
    wx.request({
      url: 'http://120.55.4.95:3000/api/user/update',
      method: 'POST',
      data: {
        userId: user.id, // 从登录响应中获得的用户ID
        nickName: userInfo.nickName,
        avatarUrl: userInfo.avatarUrl
      },
      success: (response) => {
        if (response.data.success) {
          console.log('用户信息更新成功');
          // 更新本地显示
          that.setData({
            user: response.data.user
          });
        } else {
          console.error('用户信息更新失败:', response.data.message);
        }
      },
      fail: (error) => {
        console.error('网络请求失败:', error);
      }
    });
  },
  fail: (error) => {
    console.error('获取用户信息失败:', error);
  }
});
```

## 数据库更新说明

该接口会更新用户表中的以下字段：
- `nickName` - 用户昵称
- `avatarUrl` - 用户头像URL
- `updatedAt` - 更新时间

## 注意事项

1. **用户隐私**：只有在用户主动授权后才能获取真实头像和昵称
2. **数据验证**：接口会对输入参数进行验证，确保数据完整性
3. **错误处理**：包含完整的错误处理和日志记录
4. **数据库兼容**：如果数据库不可用，仍然会返回成功响应，但不会实际更新数据
